# Xudbin belgeleri / Xudbin documentation

Bu klasör Xudbin'in kullanıcı belgelerini içerir: Türkçe sayfalar `tr/`, İngilizce sayfalar `en/` klasöründedir ve iki klasörde de aynı dosya adları kullanılır (`NN-konu.md`, NN okuma sırasıdır), böylece bir sayfanın diğer dildeki karşılığı hep aynı addadır. Her sayfa tek bir `#` başlığı ve bir cümlelik özetle başlar; xudbin.com bu dosyaları doğrudan okuyup belgeler sitesi olarak gösterir. — This folder holds the Xudbin user documentation: Turkish pages live in `tr/`, English pages in `en/`, and both folders use identical file names (`NN-slug.md`, where NN is the reading order) so each page maps to its translation; every page starts with a single `#` title and a one-sentence summary, and xudbin.com renders these files as the documentation site.
